# Documentation

This directory is a lightweight documentation hub for the repository.

The current repository focus remains practical FinOps automation, especially executable and independent scripts. The documentation structure here is intentionally simple so it can grow over time without forcing the project into a heavier platform or site model too early.

## Available Documents

- [Documentation Landing Page](./index.html)
- [Contributing Guide (English)](../CONTRIBUTING.md)
- [Guia de Contribuicao (Portuguese)](../CONTRIBUTING.pt-BR.md)

## Suggested Evolution

If the organization later decides to publish a broader documentation site, this directory can serve as the base for:

- GitHub Pages using the `docs/` folder
- MkDocs or another static documentation generator
- a future central documentation repository shared across FinOps automation projects

## Repository Direction

For now, documentation should support the practical goals of the project:

- help contributors understand how to add or improve scripts
- explain FinOps expectations clearly
- keep guidance readable, reusable, and easy to maintain
