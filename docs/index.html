What This Project Solves

FinOps is not only about visibility. It is also about execution. This project helps teams identify and act on opportunities related to cost reduction, operational efficiency, and governance through practical automation.

Current Repository Focus

The current priority is standalone scripts that are easy to understand, safe to run, and reusable across different environments. The documentation is intentionally lightweight so it can evolve without forcing a premature platform model.

Contribution Model

What Good Contributions Look Like

Focused Scripts

Prefer one script solving one clear FinOps problem with simple execution and minimal dependencies.

Safe Defaults

Use parameters, logging, and dry-run behavior whenever possible. Avoid destructive actions by default.

Open Source Ready

Keep code reusable, readable, maintainable, tested, and free from sensitive or environment-specific data.
